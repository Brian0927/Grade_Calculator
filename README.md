# Grade_Calculator

清大六科繁體中文互動成績計算器。下載 `index.html` 後以瀏覽器開啟即可離線使用，無需安裝套件。

## 功能

- 電路學、工程數學、機械製造、基礎熱流學一、中級德文、材料力學。
- 空白代表未知，0 分有效；計算各等第所需剩餘加權平均、單項最低分與不可能狀態。
- 每科獨立調分開關：自訂平移分數或原始加權總分開根號乘以十。
- 分別列出調分前後總分、等第、績分與學分加權 GPA；請輸入各科實際學分。
- 瀏覽器本機保存、JSON 備份匯出與匯入。成績不會傳送至伺服器。

## 計算說明

GPA 採逐科等第績分乘以學分後加權平均。未填齊成績、未填學分、無效資料與零學分科目不納入；不及格科目仍納入。單項最低分假設其他未知項目全部取得 100 分，不可同時使用各項下限作為達標組合。總分不預先四捨五入；調分為假設情境，實際等第由教師決定。

等第與績分依[清大官方教師網路輸入成績說明](https://registra.site.nthu.edu.tw/var/file/211/1211/img/75/369625152.pdf)第 2 頁。詳細權重、公式及來源見頁面內說明。
